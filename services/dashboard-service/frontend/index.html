Query Refinement

Refine a raw query before retrieval — spell-correction (SymSpell) + optional synonym expansion (WordNet). Full control over every option this service exposes.

Query

Refinement runs on the raw query (before normalization), so a misspelling like infromation is corrected before it reaches the index. Synonym expansion broadens recall but can hurt precision — that's why it's off by default and evaluated before/after.

Result

Refine a query to see corrections, added terms & suggestions here.

Evaluation

Measure each representation against the qrels — MAP, nDCG, Recall, P@10. The most-graded part of the project; reports are saved & labeled for before/after comparison, with charts.
